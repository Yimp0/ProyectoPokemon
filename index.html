        ¿Cómo utilizar la aplicación?

        Ingresa al Teambuilder, busca un Pokémon, agrégalo y personaliza su habilidad, objeto, naturaleza, movimientos, EVs e IVs. Puedes guardar hasta seis integrantes.

        Busca Pokémon por nombre o número, filtra por tipo y abre cada tarjeta para consultar información detallada.

        Selecciona uno de los Pokémon guardados y enfréntalo a un rival generado por la aplicación en una batalla de prueba.

        El equipo se conserva en el navegador mediante LocalStorage. También puedes importarlo o exportarlo en formato compatible con Pokémon Showdown.

        Sobre el proyecto

        Aplicación web educativa desarrollada para demostrar integración de estructura, estilos e interactividad.

        • HTML5: estructura semántica.
        • CSS3: Flexbox, Grid, animaciones y media queries.
        • JavaScript: DOM, eventos, validación y lógica dinámica.
        • PokéAPI: consulta de datos y sprites.
        • LocalStorage: persistencia del equipo.
        • WebSocket: base del modo multijugador.
        Consejo: crea primero un equipo para habilitar todas las experiencias.
